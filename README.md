# Beyond the Bifactor: A Multi-Paradigm Machine Learning Framework ($DT^3$)

**Short Internal Name:** The Dark Triad Triangulation Project ($DT^3$)

## Project Summary
This project re-examines a foundational debate in personality psychology: are Machiavellianism, Narcissism, and Psychopathy (the "Dark Triad") genuinely distinct psychological constructs, or are they three surface expressions of a single underlying "Dark Core"? 

Instead of relying solely on Confirmatory Factor Analysis (CFA) or bifactor models, this repository implements a **multi-paradigm machine learning triangulation framework** combining:
1. **Unsupervised Graph Structure** (Gaussian Graphical Models & Mapper TDA)
2. **Supervised Multi-Task Machine Learning** (Shared-Trunk Neural Networks & SHAP Attribution)
3. **Causal Inference & Counterfactuals** (PC Algorithm & DiCE)
4. **Semantic Vector Analysis** (LLM Item Embeddings)
5. **Statistical Rigor & Robustness** (Conformal Prediction, Rashomon Sets, SDI)

## Dataset
Uses the publicly available, OSF-hosted dataset from the **Czech Dark Triad Dirty Dozen (DTDD) Validation Study** ($N > 6,700$).

## Team & Roles

* **AI/ML Lead:** Data engineering, model implementation, statistical validation, reproducibility infrastructure.
