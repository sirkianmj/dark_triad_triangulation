## 2. Executive Summary
Re-examines whether Machiavellianism, Narcissism, and Psychopathy are distinct constructs or expressions of a single latent "Dark Core" using a multi-paradigm machine learning framework. Combines supervised learning, graph structure, causal inference, topological data analysis, symbolic regression, representational similarity analysis, and LLM semantic embeddings on OSF dataset (N > 6,700).

## 3. Methodological Framework & Roadmap
- **Layer 1:** Gaussian Graphical Model Network Psychometrics & Mapper TDA.
- **Layer 2:** Shared-Trunk Multi-Task Neural Network, SHAP, CKA/RSA, Symbolic Regression, NAM.
- **Layer 3:** Causal Discovery (PC/GES) & DiCE Counterfactual Explanations.
- **Layer 4:** LLM Sentence Embedding Semantic Clustering.
- **Layer 5:** Formal SHAP Divergence Index, Conformal Prediction, Rashomon Sets, Subtype Clustering.
